# Manitoba Agricultural Data Portal: online demo

A public copy of the Phase 1 prototype interface. **All values, identifiers, connections and boundaries are fabricated demonstration data.** It is not an official or operational system.

This hosted copy uses pre-generated answers for five example questions. The full prototype also runs a local language model, which is not part of this site.

Live demo: https://digitalagroecosystemslab.github.io/manitoba-data-hub-demo/
